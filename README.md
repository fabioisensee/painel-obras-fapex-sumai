# Painel de Obras e Reformas — FAPEX · SUMAI · UFBA

Visualização somente leitura do acompanhamento de obras e reformas conduzidas
pela FAPEX em parceria com a SUMAI/UFBA.

## Como acessar

Abra o link do GitHub Pages deste repositório e informe seu código de acesso
pessoal na tela inicial. Cada pessoa autorizada tem um código próprio.

## Sobre a segurança deste arquivo

Este repositório contém **apenas** um arquivo HTML autocontido
(`index.html`). Os dados de obras, valores e empresas ficam **cifrados**
dentro do próprio arquivo (PBKDF2 + AES-GCM, via WebCrypto do navegador) e só
são decifrados no navegador de quem digitar um código válido — nenhum dado
fica legível sem o código correto, mesmo estando o arquivo publicado
publicamente aqui.

Nenhuma credencial do Trello, script de geração ou lista de códigos de acesso
faz parte deste repositório.

## Atualização

Este arquivo é gerado automaticamente a partir do quadro do Trello e
republicado periodicamente. Não deve ser editado manualmente.
